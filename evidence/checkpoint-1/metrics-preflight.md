# Проверка схемы метрик

Источник: [`sample-journal.ndjson`](sample-journal.ndjson). Это синтетический пример для проверки полей и формул, не экспериментальный результат FoundationDB.

| Показатель | Расчёт | Результат |
|---|---|---:|
| Conflict rate | 1 `not_committed` / 3 commit attempts | 33,3% |
| Retry rate | 1 транзакция с повтором / 2 завершённые | 50% |
| Throughput | 2 подтверждения / 2 с | 1,0 tx/s |
| Логические latency | `tx-001`: 30 мс; `tx-002`: 130 − 40 = 90 мс | 30, 90 мс |
| p95/p99, nearest-rank | по двум latency | 90 / 90 мс |
| Потерянные подтверждённые записи | 2 подтверждения − 2 маркера | 0 |

Проверка цепочки для `counter/0`: `0 → 1 → 2`, итоговое значение `2`, маркеров `2`. Полей журнала хватает для обязательных метрик и выбранного checker. В реальных запусках источник `synthetic` заменяется на фактические события клиента и кластера.
