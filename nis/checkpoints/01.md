# Контрольная точка 1

## Краткий результат

Зафиксированы технический путь, проверяемые результаты и план серии из 30 запусков. Официальный ARM64-образ FoundationDB локально запущен; база стала доступна, транзакция `set/get/commit` подтверждена. Полный многопроцессный сценарий к первой точке не заявляется выполненным.

## Проверенные технические предпосылки

| Проверка | Команда | Ожидаемый результат | Полученный результат |
|---|---|---|---|
| Запуск артефакта | `./scripts/checkpoint1-smoke.sh` | FoundationDB стартует на ARM64 | База доступна |
| Транзакционный API | та же команда | `set/get/commit` сохраняет `ok` | Коммит подтверждён, повторный `get` вернул `ok` |
| Воспроизводимость версии | `docker image inspect foundationdb/foundationdb@sha256:3d47...` | Зафиксированы digest и архитектура | `sha256:3d47...`, Linux/ARM64 |
| Схема измерений | ручная проверка пробного NDJSON | Полей хватает для обязательных метрик и checker | Конфликты, повторы, throughput, latency и инвариант рассчитаны |

Использованный smoke-test поднимает один процесс с memory storage. Он подтверждает совместимость артефакта и базовую транзакцию, но не отказоустойчивость.

## Фактические ресурсы и измеримость показателей

- MacBook Pro, Apple M4 Pro, 14 ядер, 48 ГБ RAM.
- Docker client `29.4.0`, server `29.2.1`, Linux/ARM64 VM.
- Требование задания 8–16 ГБ памяти укладывается в доступные ресурсы.
- Conflict/retry rate и latency собираются из журнала клиента; throughput считается по подтверждённым логическим транзакциям; событие отказа имеет монотонную метку времени; подтверждённые записи сверяются с маркерами в базе.
- [Пробный журнал](../../evidence/checkpoint-1/sample-journal.ndjson) содержит необходимые поля; [контрольный расчёт](../../evidence/checkpoint-1/metrics-preflight.md) показывает их измеримость. Это синтетическая проверка схемы, не результат эксперимента.
